# Nexus

Desktop time tracker for Windows. Track categories with play/stop, notes, and week/month analytics. Times stay on this computer.

## Run

1. Install [Python 3.12+](https://www.python.org/downloads/).
2. Install the dependency:

```bash
python -m pip install -r requirements.txt
```

3. Double-click `Start Time Widget.bat`.

The window opens compact. Drag an edge or corner to resize. **Stay on top** is in Settings.

Tracked time is written to `data/time_data.json` and is not part of this repository.
